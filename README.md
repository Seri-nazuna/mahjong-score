# 麻雀 点数計算機

翻と符、親か子か、ロンかツモかを選ぶと、和了点と支払いの内訳を表示するツールです。

公開ページ：https://seri-nazuna.github.io/mahjong-score/

## 機能

- **点数の表示**：合計点と、満貫・跳満などの呼び名を表示します
- **支払いの内訳**：ツモのときは親と子それぞれの支払い額を分けて表示します
- **点棒の表示**：支払い額を点棒の組み合わせで表示します
- **切り上げ満貫の切り替え**：30符4翻・60符3翻を満貫として扱うかを選べます
- **組み合わせの確認**：20符のロンなど、実戦で起こらない組み合わせを選ぶと注意を表示します

13翻以上は数え役満として扱います。リーチ棒・本場・積み棒は含みません。
